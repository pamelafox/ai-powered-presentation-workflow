# Mini talk plan: Three ways to make a Python web app

## Audience

Python learners who have written scripts and want a quick map of common Python web app options.

## Goal

By the end, the audience should understand three common paths for building a Python web app and how to choose a starting point.

## Constraints

- 3 to 5 minutes
- 4 to 6 slides
- Include one concrete comparison
- Use simple speaker notes

## Draft outline

1. Why there is more than one Python web path
2. Flask: small and flexible
3. FastAPI: APIs with type hints and docs
4. Django: full-featured framework
5. Final takeaway: choose based on project shape

## Speaker-note guidance

- Keep the comparison practical rather than exhaustive.
- Use a simple app idea, such as a recipe tracker or event signup page, and explain which framework might fit.
- Avoid declaring one framework the best. Each one has a natural use case.
