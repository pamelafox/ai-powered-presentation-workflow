# Mini talk plan: Intro to vector search

## Audience

Developers who have heard about embeddings or retrieval-augmented generation, but have not yet built a vector search feature.

## Goal

By the end, the audience should understand that vector search finds items by meaning rather than exact keyword match.

## Constraints

- 3 to 5 minutes
- 4 to 6 slides
- Include one concrete example
- Use simple speaker notes

## Draft outline

1. Why keyword search is not always enough
2. What an embedding represents
3. How vector search compares meaning
4. Example: finding similar support tickets or documentation pages
5. Final takeaway: use vector search when meaning matters

## Speaker-note guidance

- Avoid heavy math. Use a visual analogy like points near each other on a map.
- Make clear that vector search does not replace every search feature.
- Mention that the quality depends on the embedding model, the data, and the retrieval strategy.
